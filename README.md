# Math Graph Studio v2

GitHub Pagesで公開できる数学関数グラファー。

## v2
- 複数関数
- 微分（math.js）
- 実数零点の数値検出
- 接線
- 数値積分
- 極座標
- ダークモード
- Plotlyのズーム・パン

## 公開
GitHubでPublic repositoryを作成し、4ファイルをアップロード。
Settings → Pages → Deploy from a branch → main → /(root) → Save。

公開URL:
`https://ユーザー名.github.io/リポジトリ名/`

## 注意
math.jsとPlotlyをCDNから読み込むため、公開サイトの利用にはインターネット接続が必要です。
